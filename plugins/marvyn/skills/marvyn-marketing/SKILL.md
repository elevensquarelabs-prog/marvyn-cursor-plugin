# Marvyn marketing

## When to use

- "How are my ads doing?", "Which campaign is wasting money?", "Why did traffic drop?"
- Checking tracking or conversion setup before shipping a landing page or a pixel change
- Turning Marvyn's alerts and recommendations into a short to-do list

## Instructions

1. Start with `get_marketing_summary` for a broad question; use the specific tool (`get_campaign_performance`, `get_creative_performance`, `get_search_visibility`, `get_conversion_funnel`, `get_tracking_health`) when the question names an area.
2. Check `get_marvyn_alerts` when the user asks what is wrong or what changed.
3. Quote numbers with their period and source exactly as the tools return them. Do not estimate missing figures.
4. Marvyn never changes, pauses or publishes anything without the user's approval inside Marvyn. If the user asks for a change, say it must be approved in Marvyn.
5. If a tool says an account is not connected or needs reconnecting, tell the user to fix it in Marvyn under Integrations.
